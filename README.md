# StudentPortal Frontend

React and Vite frontend for the StudentPortal Admin, Teacher, and Student portals.

## Development

```powershell
npm install
npm run dev
```

Set `VITE_API_URL` when the API is hosted at a different base URL. By default, requests use `/api/v1`; the Vite development proxy forwards them to the backend.
